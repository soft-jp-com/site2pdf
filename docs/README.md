# site2pdf ドキュメント

`site2pdf` は、Google Chrome を制御して Web ページを **PDF・プレーンテキスト・構造化JSON** に変換・抽出する高性能な Go 製 CLI ツール / ライブラリです。

---

## 主な特徴

1. **マルチフォーマット出力**:
   - **PDF生成 (`--format pdf`)**: 完全なレイアウトとスタイルを保持したPDFの生成。
   - **テキスト抽出 (`--format text` / `--text`)**: ページのクリーンなプレーンテキスト出力。
   - **構造化データ抽出 (`--format json` / `--json`)**: タイトル、公開日時、メタ情報、メイン本文（ナビ・広告・スクリプト除去済み）、全体テキストを構造化して出力（`fnews` 等の他システムと直接連携可能）。
   - **一括出力 (`--format all`)**: PDF、Text、JSON のすべてを同時に生成。
2. **2つの実行モード（CDP接続 / ヘッドレスChrome）**:
   - **CDPモード（起動中ブラウザ接続）**: 普段使用している Chrome（`--remote-debugging-port` 有効）に接続し、**ログイン状態・クッキー・セッションを維持したまま** ページを取得・変換。
   - **ヘッドレスChromeモード**: 自動検出した Chrome をバックグラウンドで起動して変換。
3. **動的サイト（SPA: Single Page Application）の完全描画**:
   - React / Vue / Next.js などの JavaScript で描画されるサイトや内部スクロールコンテナを適切に展開して処理。
4. **一括処理 & クロール機能**:
   - 単一URL処理 (`--url https://...`)
   - `sites.json` 定義ファイルに基づく複数ドキュメントの一括変換 (`--sites sites.json`)
   - 単一URLからの同一ドメイン巡回クロール (`--crawl --url https://...`)
